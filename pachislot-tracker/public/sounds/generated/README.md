# 生成サウンド (パチスロ風 効果音・BGM)

`scripts/generate_sounds.py` によって NumPy の波形合成で一から作られた
オリジナルの効果音・BGM です。実機のサウンドを録音・複製したものでは
なく、パチスロらしい雰囲気を再現するために合成したフリー素材（私用目的）
です。

音を厚く・重厚にするために以下の手法を重ねています。

- **ユニゾン/デチューン**: 複数の波形を微妙に音程をずらして重ねるコーラス効果
- **加算合成のブラス/ベルトーン**: 倍音を積み上げてビブラートを加えた厚みのある音色
- **サブベース**: 1オクターブ下の正弦波を重ねて低域の重みを追加
- **疑似リバーブ**: 合成インパルス応答との畳み込みによる空間の広がり（ループ素材は循環畳み込みでシームレス性を維持）
- **ソフトサチュレーション**: tanh による倍音付加で音を太く・温かく
- **ステレオ化**: ハース効果による自然な広がり
- **フルドラムバス**: キック・スネア・ハイハットを重ねた BGM ループ用のリズムトラック

## 再生成

```bash
pip install numpy
sudo apt-get install ffmpeg   # ffmpeg が未インストールの場合
python3 scripts/generate_sounds.py
```

`scripts/generate_sounds.py` 内のパラメータ（音階・BPM・エンベロープなど）
を変更することで、音色やフレーズを自由にアレンジできます。
