# 生成サウンド (パチスロ風 効果音・BGM)

`scripts/generate_sounds.py` によって一から作られたオリジナルの効果音・BGM
です。実機のサウンドを録音・複製したものではなく、パチスロらしい雰囲気を
再現するために合成したフリー素材（私用目的）です。

効果音は NumPy の波形合成のみで作っていますが、BGM/ファンファーレは
それに加えて **FluidSynth + General MIDI サウンドフォント**でパッド/
リード/ベースを実際のサンプル音色でレンダリングしています。自作
オシレーター（矩形波・ノコギリ波など）だけではどうしても出せない
「本物の楽器/シンセの音色」に近づけるための工夫です。

BGM は EDM/トランス系の方向性で作り込んでおり、以下の手法を重ねています。

- **サウンドフォント音色**: パッド/リード/ベースは FluidSynth で GM サウンドフォント（Pad 2 warm / Lead 2 sawtooth / Synth Bass 2）をレンダリングした実サンプル音
- **トランス進行**: 定番の I-V-vi-IV(C-G-Am-F) ではなく、ジャンルに定番の Am-G-F-E(i-VII-VI-V) 進行を使用
- **曲構成**: 静的なループではなく、イントロ(パッドのみ)→ビルドアップ(ハット+スパースなリード)→ドロップ(四つ打り+アルペジオ)という起伏のある構成
- **スウィング/ヒューマナイズ**: タイミングとベロシティに揺らぎを持たせ、完全グリッドの「打ち込み臭さ」を軽減
- **サイドチェイン（ポンピング）**: キックに合わせてパッド/リード/ベースを一瞬ダッキングさせる EDM 特有のうねり
- **自作ドラム**: キック・クラップ(ゲートリバーブ)・16分ハットは NumPy 合成でパンチを作り込み
- **ライザー**: ドロップ/ファンファーレ前に緊張感を煽る上昇サウンド
- **ユニゾン/デチューン・加算合成のブラス/ベルトーン**: 効果音・ファンファーレ側で使用
- **疑似リバーブ / ソフトサチュレーション / ステレオ化**: 空間の広がりと温かみ、自然な広がり

## 再生成

```bash
pip install numpy
sudo apt-get install ffmpeg fluidsynth fluid-soundfont-gm musescore-general-soundfont
python3 scripts/generate_sounds.py
```

`scripts/generate_sounds.py` 内のパラメータ（コード進行・BPM・曲構成・
サウンドフォントの GM プログラム番号など）を変更することで、音色や
フレーズ、曲展開を自由にアレンジできます。
